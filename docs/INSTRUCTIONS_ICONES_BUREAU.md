# 🖥️ Instructions : Icônes sur le Bureau Windows

## 🎯 Objectif

Créer **2 icônes sur votre bureau Windows** pour utiliser Facturación Fácil :
- **🚀 Une icône pour lancer** l'application
- **🔄 Une icône pour mettre à jour** l'application

## 📋 Instructions Étape par Étape

### **Étape 1 : Télécharger l'application**
1. Télécharger le fichier ZIP depuis GitHub
2. Extraire le ZIP dans un dossier (ex: `Documents\Facturacion_Facil`)
3. Ouvrir le dossier extrait

### **Étape 2 : Créer les icônes sur le bureau**
1. Dans le dossier de l'application, chercher le fichier : **`creer_icones_bureau.bat`**
2. **Double-cliquer** sur ce fichier
3. Répondre **"O"** quand demandé
4. Attendre que le script termine

### **Étape 3 : Vérifier les icônes**
1. **Regarder sur votre bureau Windows**
2. Vous devriez voir **2 nouvelles icônes** :
   - 🚀 **Facturación Fácil**
   - 🔄 **Mise à Jour Facturación Fácil**

## 🖥️ Où Trouver les Icônes

### **Sur le Bureau Windows**
Les icônes apparaissent directement sur votre **bureau Windows** (Desktop) :

```
🖥️ Bureau Windows
├── 🚀 Facturación Fácil.lnk
├── 🔄 Mise à Jour Facturación Fácil.lnk
├── (autres icônes existantes...)
└── Corbeille
```

### **Emplacement exact**
- **Chemin** : `C:\Users\[VotreNom]\Desktop\`
- **Fichiers créés** :
  - `🚀 Facturación Fácil.lnk`
  - `🔄 Mise à Jour Facturación Fácil.lnk`

## 🎮 Utilisation des Icônes

### **🚀 Pour lancer l'application**
1. **Double-cliquer** sur l'icône `🚀 Facturación Fácil`
2. L'application se lance automatiquement
3. Aucune configuration nécessaire

### **🔄 Pour mettre à jour l'application**
1. **Double-cliquer** sur l'icône `🔄 Mise à Jour Facturación Fácil`
2. Le système vérifie les mises à jour sur GitHub
3. Télécharge et installe automatiquement les nouveautés

## 🔍 Vérification

### **Si vous ne voyez pas les icônes**
1. **Actualiser le bureau** : Clic droit sur le bureau → "Actualiser"
2. **Vérifier** : Exécuter `verifier_icones_bureau.bat`
3. **Recréer** : Relancer `creer_icones_bureau.bat`

### **Script de vérification**
Pour vérifier que les icônes sont bien créées :
1. Double-cliquer sur **`verifier_icones_bureau.bat`**
2. Le script vous dira si les icônes sont présentes
3. Propose de les recréer si nécessaire

## 🚨 Résolution de Problèmes

### **Problème : Icônes non visibles**
**Causes possibles :**
- Bureau non actualisé
- Permissions insuffisantes
- Antivirus bloquant la création

**Solutions :**
1. Clic droit sur le bureau → "Actualiser"
2. Exécuter `creer_icones_bureau.bat` en tant qu'administrateur
3. Ajouter le dossier aux exceptions de l'antivirus

### **Problème : Icônes créées mais ne fonctionnent pas**
**Solutions :**
1. Vérifier que Python est installé
2. Exécuter `verifier_icones_bureau.bat`
3. Recréer les icônes avec `creer_icones_bureau.bat`

### **Problème : Une seule icône visible**
**Solution :**
1. Relancer `creer_icones_bureau.bat`
2. Choisir de créer les deux icônes
3. Vérifier avec `verifier_icones_bureau.bat`

## 💡 Conseils

### **Organisation du bureau**
- Les icônes peuvent être **déplacées** sur le bureau
- Vous pouvez les **renommer** si souhaité
- Vous pouvez créer un **dossier** pour les regrouper

### **Raccourcis clavier**
- **Windows + D** : Afficher le bureau rapidement
- **F5** : Actualiser le bureau

### **Sauvegarde**
- Les icônes pointent vers les scripts dans le dossier de l'application
- **Ne pas supprimer** le dossier de l'application
- **Ne pas déplacer** le dossier de l'application

# ⚡ Démarrage Rapide - Mise à Jour Windows

## 🎯 Mise à jour en 3 clics

### **Méthode ultra-rapide**
```
1. Double-clic sur update.bat
2. Suivre les instructions à l'écran
3. C'est tout! 🎉
```

## 🔧 Scripts disponibles

### **🔄 update.bat**
- **Usage** : Mise à jour automatique complète
- **Durée** : 2-5 minutes
- **Action** : Double-clic et suivre les instructions

### **💾 backup.bat**
- **Usage** : Sauvegarde avant mise à jour
- **Durée** : 30 secondes
- **Action** : Double-clic pour sauvegarder

### **🔄 restore.bat**
- **Usage** : Restaurer une sauvegarde
- **Durée** : 1-2 minutes
- **Action** : Choisir la sauvegarde à restaurer

### **🔍 diagnostic_update.bat**
- **Usage** : Vérifier l'état avant mise à jour
- **Durée** : 30 secondes
- **Action** : Diagnostic complet + actions recommandées

## 🚨 Cas d'urgence

### **Problème pendant la mise à jour**
```batch
1. Fermer la fenêtre de mise à jour
2. Double-clic sur diagnostic_update.bat
3. Suivre les recommandations
```

### **Application ne démarre plus**
```batch
1. Double-clic sur restore.bat
2. Choisir la dernière sauvegarde
3. Relancer l'application
```

### **Perte de données**
```batch
1. Aller dans le dossier backups\
2. Chercher facturacion_backup_YYYYMMDD.db
3. Copier vers facturacion.db
```

## ⚡ Workflow recommandé

### **Mise à jour hebdomadaire**
```
Lundi matin:
1. backup.bat (sauvegarde)
2. update.bat (mise à jour)
3. Tester l'application
```

### **Avant une mise à jour importante**
```
1. backup.bat (sauvegarde)
2. diagnostic_update.bat (vérification)
3. update.bat (mise à jour)
4. Test complet de l'application
```

## 🎯 Indicateurs visuels

### **✅ Mise à jour réussie**
- Message "MISE À JOUR TERMINÉE AVEC SUCCÈS!"
- Proposition de lancer l'application
- Aucun message d'erreur rouge

### **⚠️ Attention requise**
- Messages en jaune
- Demandes de confirmation
- Suggestions d'actions

### **❌ Erreur**
- Messages en rouge
- Instructions de résolution
- Suggestion d'utiliser diagnostic_update.bat

## 📱 Notifications

### **Mises à jour disponibles**
L'application peut afficher :
- 🔔 Popup de notification
- 📊 Badge dans l'interface
- 📧 Email (si configuré)

### **Actions recommandées**
- **Critique** : Mettre à jour immédiatement
- **Important** : Mettre à jour dans la semaine
- **Mineur** : Mettre à jour quand possible

## 🛠️ Dépannage express

### **"Git n'est pas installé"**
```
1. Aller sur https://git-scm.com/download/win
2. Télécharger et installer Git
3. Redémarrer l'ordinateur
4. Relancer update.bat
```

### **"Python non trouvé"**
```
1. Double-clic sur install.bat
2. Suivre les instructions d'installation
3. Relancer update.bat
```

### **"Environnement virtuel manquant"**
```
1. Double-clic sur install.bat
2. Attendre la création de l'environnement
3. Relancer update.bat
```

### **"Application en cours d'exécution"**
```
1. Fermer complètement l'application
2. Vérifier dans le gestionnaire des tâches
3. Relancer update.bat
```

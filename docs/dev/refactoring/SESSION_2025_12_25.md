## 📝 Notes Techniques

### Pattern de Test pour les Services

**Utiliser `unittest.TestCase`** au lieu de `BaseTestWithFixtures` :

```python
import unittest
import tempfile
import os
from services.some_service import SomeService

class TestSomeService(unittest.TestCase):
    def setUp(self):
        self.temp_db = tempfile.NamedTemporaryFile(delete=False, suffix='.db')
        self.temp_db.close()
        self.service = SomeService(self.temp_db.name)
    
    def tearDown(self):
        if os.path.exists(self.temp_db.name):
            os.unlink(self.temp_db.name)
```

### Gestion du stock_minimo

La table `stock` actuelle n'a pas de colonne `stock_minimo`. Structure actuelle :

```sql
CREATE TABLE stock (
    producto_id INTEGER PRIMARY KEY,
    cantidad_disponible INTEGER DEFAULT 0,
    fecha_actualizacion TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (producto_id) REFERENCES productos (id)
)
```

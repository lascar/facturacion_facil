# 🚀 Sistema de Instalación Completo - Facturación Fácil

## 📋 Descripción

Sistema completo de instalación, desinstalación y mantenimiento para la aplicación **Facturación Fácil**. Incluye instalación automática de dependencias, creación de iconos de acceso directo y scripts de mantenimiento.

## 🎯 Características Principales

### ✅ Instalación Automática
- **Detección automática de Python** (instala si no existe)
- **Configuración de entorno virtual** automática
- **Instalación de dependencias** desde requirements.txt
- **Verificación de funcionamiento** de PyQt5
- **Creación automática de iconos** de acceso directo

### ✅ Iconos de Acceso Directo
- **🚀 Lanzar Facturación Fácil** - Ejecutar la aplicación
- **🔄 Actualizar desde Git** - Actualizar código automáticamente
- **🗑️ Desinstalar Aplicación** - Desinstalación completa
- **🔧 Reinstalar Aplicación** - Reinstalación limpia
- **📊 Abrir Base de Datos** - Acceso a la carpeta de base de datos
- **📄 Ver PDFs Generados** - Acceso a facturas PDF
- **⚙️ Configuración** - Acceso a archivos de configuración
- **📝 Logs de la Aplicación** - Ver logs del sistema

### ✅ Mantenimiento Automático
- **Actualización desde Git** con backup automático
- **Desinstalación segura** (preserva datos importantes)
- **Reinstalación limpia** sin perder configuración
- **Detección y resolución** de problemas comunes

## 🚀 Instalación Rápida

### Opción 1: Configuración Completa (Recomendado)
```batch
configurar_sistema_completo.bat
```
Este script hace todo automáticamente:
- Instala Python si es necesario
- Configura el entorno virtual
- Instala todas las dependencias
- Crea todos los iconos de acceso directo
- Configura Git para actualizaciones

### Opción 2: Instalación Manual Paso a Paso
```batch
# 1. Instalar la aplicación
instalar_app.bat

# 2. Crear iconos personalizados
crear_iconos_personalizados.bat

# 3. Configurar Git (opcional)
actualizar_git_mejorado.bat
```

## 🛡️ Seguridad y Backup

### 💾 Datos Preservados
Durante la desinstalación se **conservan**:
- ✅ Base de datos (`facturacion.db`)
- ✅ PDFs generados (`pdfs/`)
- ✅ Configuración (`config/config.json`)
- ✅ Logos personalizados (`data/logos/`)

### 🗑️ Datos Eliminados
Durante la desinstalación se **eliminan**:
- ❌ Entorno virtual (`venv/`)
- ❌ Cache de Python (`__pycache__/`)
- ❌ Archivos temporales (`.tmp`, `.log`, `.bak`)
- ❌ Logs (opcional, se pregunta al usuario)

### 📦 Backup Automático
- **Backup antes de actualizar** desde Git
- **Backup de configuración** y base de datos
- **Restauración automática** en caso de error

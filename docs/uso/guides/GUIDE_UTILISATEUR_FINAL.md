# 🎯 Guide Utilisateur Final - Facturación Fácil

## 🚀 Installation Ultra-Simple

### **Étape 1 : Télécharger l'application**
```
1. Aller sur GitHub (lien fourni par le développeur)
2. Cliquer sur "Code" → "Download ZIP"
3. Extraire le ZIP dans un dossier (ex: Documents\Facturacion_Facil)
```

### **Étape 2 : Créer les icônes**
```
1. Ouvrir le dossier de l'application
2. Double-cliquer sur "setup_icons.bat"
3. Choisir "3" (les deux icônes)
4. Attendre la fin de la création
```

### **Étape 3 : C'est terminé !**
```
✅ Deux icônes apparaissent sur votre bureau :
   🚀 Facturación Fácil (pour lancer l'app)
   🔄 Mise à Jour Facturación Fácil (pour mettre à jour)
```

## 🎮 Utilisation Quotidienne

### **🚀 Lancer l'application**
```
Double-clic sur l'icône "🚀 Facturación Fácil"
→ L'application se lance automatiquement
→ Aucune configuration nécessaire
```

### **🔄 Mettre à jour l'application**

## 🚨 Résolution de Problèmes

### **Problème : L'icône ne fonctionne pas**
**Solution :**
1. Vérifier que Python est installé (télécharger depuis python.org)
2. Cocher "Add Python to PATH" lors de l'installation
3. Redémarrer l'ordinateur
4. Relancer setup_icons.bat

### **Problème : Erreur lors de la mise à jour**
**Solution :**
1. Vérifier la connexion internet
2. Installer Git (git-scm.com/download/win)
3. Relancer l'icône de mise à jour

### **Problème : L'application ne se lance pas**
**Solution :**
1. Double-cliquer sur "diagnostic_env_windows.bat"
2. Suivre les recommandations affichées
3. Ou réinstaller en relançant setup_icons.bat

## 🐍 Principes de Code Pythonic - OBLIGATOIRE ⚠️

### Philosophie générale
- ✅ **Simple is better than complex** (Zen of Python)
- ✅ **Readability counts** - Le code doit être facile à lire et comprendre
- ✅ **Explicit is better than implicit** - Être clair dans les intentions
- ✅ Utiliser les forces de Python : lisibilité, simplicité, expressivité

### 1. Préférer les Fonctions aux Classes - OBLIGATOIRE ⚠️
- ✅ **RÈGLE** : Commencer TOUJOURS par des fonctions
- ✅ **RÈGLE** : N'ajouter des classes QUE si elles apportent une vraie valeur
- ❌ **INTERDICTION** : Créer des classes sans variables membres
- ❌ **INTERDICTION** : Créer des classes qui ne servent qu'à regrouper des fonctions
- 💡 **EXEMPLE** : Si une classe n'a que des méthodes et pas d'état → utiliser des fonctions
- 🎯 **AVANTAGE** : Plus facile à tester, plus simple, moins de boilerplate

### 2. Utiliser les Context Managers - OBLIGATOIRE ⚠️
- ✅ **OBLIGATOIRE** : Utiliser `with` pour ouvrir des fichiers
- ❌ **INTERDICTION** : Ouvrir/fermer manuellement les fichiers
- 💡 **RAISON** : Gestion automatique des ressources, même en cas d'erreur
```python
# ❌ MAUVAIS
f = open('file.txt', 'r')
data = f.read()
f.close()

# ✅ BON
with open('file.txt', 'r') as f:
    data = f.read()
```

### 3. Annotations de Type - OBLIGATOIRE ⚠️
- ✅ **OBLIGATOIRE** : Ajouter des annotations de type à TOUTES les fonctions
- ✅ **OBLIGATOIRE** : Annoter les paramètres ET les valeurs de retour
- ✅ **OBLIGATOIRE** : Annoter les types de collections (List[int], Dict[str, Any], etc.)
- 💡 **AVANTAGE** : Meilleure lisibilité, détection d'erreurs, aide de l'IDE
```python
# ❌ MAUVAIS
def process_data(items, count):
    return items[:count]

# ✅ BON
def process_data(items: list[str], count: int) -> list[str]:
    return items[:count]
```

### 4. EAFP vs LBYL - Préférer EAFP ⚠️
- ✅ **PRÉFÉRER** : EAFP (Easier to Ask Forgiveness than Permission)
- ❌ **ÉVITER** : LBYL (Look Before You Leap)
- 💡 **PRINCIPE** : Essayer d'abord, gérer l'erreur ensuite
```python
# ❌ LBYL (moins pythonic)
if os.path.exists(file_path):
    with open(file_path) as f:
        data = f.read()

# ✅ EAFP (pythonic)
try:
    with open(file_path) as f:
        data = f.read()
except FileNotFoundError:
    print("Fichier non trouvé")
```

### 5. Dataclasses pour Données Structurées - OBLIGATOIRE ⚠️
- ✅ **OBLIGATOIRE** : Utiliser `@dataclass` pour les structures de données
- ✅ **AVANTAGE** : Moins de boilerplate, génération automatique de `__init__`, `__repr__`, etc.
- ✅ **UTILISER** : `field(default_factory=...)` pour valeurs par défaut dynamiques
```python
from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class Entry:
    description: str
    calories: int
    date: str = field(default_factory=lambda: datetime.now().strftime("%Y-%m-%d"))
```

### 6. Centraliser les Constantes et Chemins - OBLIGATOIRE ⚠️
- ✅ **OBLIGATOIRE** : Définir les constantes en HAUT du fichier
- ✅ **OBLIGATOIRE** : Utiliser `pathlib.Path` au lieu de strings pour les chemins
- ✅ **CONVENTION** : Constantes en MAJUSCULES
```python
from pathlib import Path

# ✅ BON - En haut du fichier
FOOD_CSV = Path("data/food.csv")
ACTIVITY_CSV = Path("data/activity.csv")
MAX_RETRIES = 3
```

### 7. Exploiter les Forces de Python - OBLIGATOIRE ⚠️
- ✅ **UTILISER** : Compréhensions de listes au lieu de boucles
- ✅ **UTILISER** : Générateurs (`yield`) pour grandes quantités de données
- ✅ **UTILISER** : Iterators au lieu de listes quand possible
```python
# ❌ MAUVAIS
result = []
for item in items:
    if item > 0:
        result.append(item * 2)

# ✅ BON
result = [item * 2 for item in items if item > 0]

# ✅ ENCORE MIEUX (pour grandes données)
def process_items(items):
    for item in items:
        if item > 0:
            yield item * 2
```

### 8. Logging au lieu de Print - OBLIGATOIRE ⚠️
- ✅ **OBLIGATOIRE** : Utiliser `logging` pour les messages de debug/info
- ❌ **INTERDICTION** : Utiliser `print()` pour le logging
- ✅ **EXCEPTION** : `print()` acceptable pour les résultats finaux du programme
```python
import logging

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logging.info("Traitement démarré")
```

### 9. Fonction Main - OBLIGATOIRE ⚠️
- ✅ **OBLIGATOIRE** : Encapsuler le code principal dans une fonction `main()`
- ✅ **OBLIGATOIRE** : Utiliser `if __name__ == "__main__":`
- 💡 **AVANTAGE** : Évite la pollution du namespace global, facilite les tests
```python
def main() -> None:
    """Point d'entrée principal du programme"""
    # Code principal ici
    pass

if __name__ == "__main__":
    main()
```

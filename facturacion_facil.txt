# Facturacion Facil - Documentation Complète de l'Interface

## Fenêtre Principale (MainWindow)
### Titre : "💼 Facturación Fácil"
### Boutons principaux (grille 3x2) :
- **📦 Productos** : Ouvre la fenêtre de gestion des produits
- **🏢 Organización** : Ouvre la fenêtre de configuration de l'entreprise
- **📊 Stock** : Ouvre la fenêtre de gestion du stock
- **🧾 Facturas** : Ouvre la fenêtre de gestion des factures
- **👥 Clientes** : Ouvre la fenêtre de gestion des clients

## Fenêtre Organización
### Section "Información Básica"
(config/config.json est le fichier où la configuration est stockée, s'il est vide ou n'existe pas, on met clés et les valeurs par défaut, on utilise celui-ci pour les inputs, logo..., si sa structure change, on essaie de migrer les anciennes valeurs vers la nouvelle structure)
- **Nombre de la Empresa** : `<input text>` (defaut: "Mi Empresa S.L.")
- **CIF/NIF** : `<input text>` (defaut: "B12345678")
- **Teléfono** : `<input text>` (defaut: "+34 911234567")
- **Email** : `<input text>` (defaut: "info@miempresa.com")

### Section "Dirección"
- **Dirección** : `<textarea>` (defaut : "Calle Mayor, 1, 28001 Madrid")

### Section "Configuración"
- **Logo de la Empresa** : `<input text>` (defaut : "logo/logo.png")
  - **Bouton 📁 Buscar** : Ouvre un sélecteur de fichier pour choisir le logo (va chercher prioritairement dans Directorio de Imágenes)
  - **Aperçu du logo** : Affichage miniature du logo sélectionné
- **Orientación del Logo** :
  - `<radio>` 🖼️ Horizontal (Landscape) - par défaut
  - `<radio>` 📱 Vertical (Portrait)
- **Número Inicial de Factura** : `<input number>` (numéro de départ pour les factures ex. 'FACT-2005-1')

### Section "Configuración de Directorios"
- **Directorio de Imágenes** : `<input text>` + **Bouton 📁 Buscar** (où l'on cherche prioritairement les images) (default : 'images/')
- **Directorio de Logos** : `<input text>` + **Bouton 📁 Buscar** (oú l'image du logo sera copiée) (default : 'logo/')
- **Directorio de PDFs** : `<input text>` + **Bouton 📁 Buscar** (où seront stockés les PDFs générés, attention si une factura est modifiable, le pdf sera recréé avec le même nom, si elle n'est pas modifiable, on cherchera s'il y a un pdf existant, sinon on le crée). le nom sera 'factura-<numéro>.pdf' (default : 'facturas/')

### Section "Configuración de Estados de Facturas"
- **Description** : `<textarea>` "Configure los estados posibles para las facturas y determine cuáles permiten modificación"
- **Tableau des états** avec colonnes :
  - Estado (nom de l'état) : `<input text>`
  - Descripción : `<textarea>`
  - Permite Modificación (checkbox)
  - Color (aperçu couleur)
  - Orden (ordre d'affichage)
(par défaut il y a 2 états : 'Borrador' (modifiable, vert) et 'Guardada' (non modifiable, orange))
- **Boutons** :
  - **➕ Agregar Estado** : Ouvre le dialogue de création d'état
  - **✏️ Editar Estado** : Ouvre le dialogue d'édition d'état
  - **🗑️ Eliminar Estado** : Supprime l'état sélectionné

### Boutons principaux
- **💾 Guardar Configuración** : Sauvegarde toute la configuration
- **🔄 Restablecer** : Recharge les données depuis la base
- **📝 TODO Editor** : Ouvre l'éditeur de tâches
- **🧹 Limpiar Datos** : Ouvre le dialogue de nettoyage des données

#### Dialogue "Configurar Estado de Factura" (InvoiceStatusDialog)
- **Titre** : `<input text>` 
- **Nombre del Estado** : `<input text>`
)
- **Descripción** : `<textarea>` 
- **Permite Modificación** : `<checkbox>` help "Permitir editar facturas en este estado"

#### Dialogue "Limpiar Datos" (DataCleanupDialog)
- **Titre** : "🧹 Limpieza de Datos de la Base de Datos"
- **Section "📊 Estado Actual de la Base de Datos"** : Affiche les statistiques actuelles
- **Section "🎯 Opciones de Limpieza"** :

## Fenêtre Facturas
### Section supérieure - Informations de la facture
- **Número de Factura** : `<input text>` (numéro automatique dernier numéro + 1 ou Número Inicial de Factura ou manuel, )
- **Fecha** : `<date picker>` (date de la facture, défaut aujourd'hui)
- **Cliente** : `<autocomplete widget>` (recherche et sélection de client)
  - Autocomplétion en temps réel
  - Création automatique de nouveau client si non trouvé
  - Format d'affichage : "Nom (NIF)"
- **Estado** : `<combobox>` (état de la facture : Borrador, Enviada, Pagada, etc.)

### Section centrale - Détails du client sélectionné
- **Nom du client** : `<label>` (nom affiché)
- **NIF/DNI** : `<label>` (numéro d'identification)
- **Dirección** : `<label>` (adresse complète)
- **Teléfono** : `<label>` (téléphone)
- **Email** : `<label>` (email)

### Section produits - "Productos de la Factura"
- **Tableau des produits** avec colonnes :
  - Producto (nom du produit, on recherche et propose les produits existants dont le nom ou la référence contient le texte saisi)
  - Cantidad (quantité)
  - Precio Unit. (prix unitaire)
  - IVA % (pourcentage IVA)
  - Descuento % (pourcentage remise)
  - Total (total ligne)

### Section ajout de produit
- **Producto** : `<autocomplete widget>` (recherche de produit)
  - Autocomplétion avec informations de stock
  - Format : "Nom - Prix€ (Stock: X)"
- **Cantidad** : `<spinbox>` (quantité à ajouter)
- **Precio Unitario** : `<input number>` (prix unitaire, pré-rempli)
- **IVA %** : `<input number>` (pourcentage IVA, pré-rempli)
- **Descuento %** : `<input number>` (pourcentage remise, défaut 0)
- **Bouton ➕ Agregar** : Ajoute le produit à la facture
(si le produit a un stock négatif ou 0 on permet avec un pop up de confirmer un stock négatif)
(la facture une fois guardée, le stock est décrémenté et cela se refléte aussi dans les produits)

### Section totaux - "Totales de la Factura"
- **Subtotal** : `<label>` (total hors taxes)
- **IVA** : `<label>` (montant total IVA)
- **Descuentos** : `<label>` (montant total remises)
- **TOTAL** : `<label>` (montant total TTC, en gras)

### Boutons principaux
- **Nueva Factura** : Crée une nouvelle factura vierge
- **Guardar** : Sauvegarde la factura actuelle
- **Eliminar** : Supprime la factura sélectionnée
- **Generar PDF** : Génère le PDF de la factura
(attention si une factura est modifiable, le pdf sera recréé avec le même nom, si elle n'est pas modifiable, on cherchera s'il y a un pdf existant, sinon on le crée). le nom sera 'factura-<numéro>.pdf')
- **Cerrar** : Ferme la fenêtre

## Widgets d'Autocomplétion

### ClientAutoCompleteWidget
- **Fonctionnalité** : Autocomplétion pour les clients avec création automatique
- **Placeholder** : "Escriba el nombre del cliente..."
- **Format d'affichage** : "Nom (NIF)" ou "Nom" si pas de NIF
- **Recherche** : Par nom ou NIF, insensible à la casse
- **Création automatique** : Si client non trouvé, propose la création
- **États visuels** :
  - Normal : bordure grise
  - Client trouvé : bordure verte, fond vert clair
  - Nouveau client : bordure orange, fond orange clair
- **Signaux émis** :
  - `client_selected` : Client existant sélectionné
  - `client_created` : Nouveau client créé
  - `client_changed` : Client changé

### ProductAutoCompleteWidget
- **Fonctionnalité** : Autocomplétion pour les produits (lecture seule)
- **Placeholder** : "Escriba el nombre del producto..."
- **Format d'affichage** : "Nom - Prix€ (Stock: X)"
- **Filtrage automatique** : Seuls les produits avec stock > 0
- **Recherche** : Par nom de produit, temps réel avec délai de 300ms
- **Validation** : Sélection obligatoire depuis la liste
- **Signaux émis** :
  - `product_selected` : Produit sélectionné
  - `product_changed` : Produit changé

## Architecture Technique

### Framework GUI
- **Framework principal** : PyQt5 (migration complète depuis CustomTkinter) - **Fenêtres** : QMainWindow, QDialog pour les dialogues modaux
- **Layouts** : QGridLayout, QVBoxLayout, QHBoxLayout pour l'organisation
- **Widgets natifs** : QLineEdit, QPushButton, QTableWidget, QComboBox, etc.

### Composants spécialisés
- **BasePyQt5Window** : Classe de base pour toutes les fenêtres secondaires
- **ScrollableMixin** : Support du scroll pour les fenêtres avec contenu long
- **Event Manager** : Gestion centralisée des événements PyQt5
- **Autocomplétion native** : QCompleter avec QStringListModel

### Signaux et communication
- **pyqtSignal** : Communication entre widgets (client_selected, product_selected, etc.)
- **Connexions automatiques** : setup_connections() dans chaque fenêtre
- **Gestion d'état** : Synchronisation temps réel entre composants

### Styles et apparence
- **Feuilles de style Qt** : CSS-like pour personnaliser l'apparence
- **Icônes** : Support des émojis et icônes dans les boutons
- **Responsive** : Adaptation automatique à la taille de fenêtre
- **Thème cohérent** : Couleurs et polices standardisées
